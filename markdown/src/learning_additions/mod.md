| 模块 | 主题 |
|------|------|
| `async_basics` | async/await 基础 |
| `cargo_features` | Cargo features 与 cfg 条件编译 |
| `collections_extra` | HashSet、BTreeMap、BTreeSet、VecDeque |
| `const_generics` | const fn 与 const 泛型 |
| `derive_macros` | #[derive(...)] 宏详解 |
| `env_process` | 环境变量与进程控制 |
| `error_handling` | Option/Result 错误处理 |
| `impl_trait` | impl Trait vs dyn Trait |
| `iterators` | 迭代器常用方法 |
| `lifetimes` | 生命周期标注 |
| `modules_and_testing` | 模块可见性与基础测试 |
| `option_result_combinators` | Option/Result 组合子链式调用 |
| `ownership_borrowing` | 所有权、借用与切片 |
| `pattern_matching` | 模式匹配 |
| `serde_basics` | serde 序列化/反序列化 |
| `testing_advanced` | 高级测试：文档测试、should_panic、ignore |
| `traits_generics` | trait 与泛型 |
